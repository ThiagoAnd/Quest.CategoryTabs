# Changelog

All notable changes to this mod are listed here. The format follows Keep a Changelog.

## [0.1.0] - 2026-10-23

### Added
- Registry of tabs for the solo category bar: other mods register an id, icon, tooltip and two callbacks.
- Free category number chosen automatically.
- Paging of the tab bar (Back, Next, n/total) when the tabs do not fit.
- Log file with a clear error line to send when reporting a problem.
